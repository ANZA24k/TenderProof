# Synthetic Tender — Incident-status dashboard

TenderProof's public pilot fixture is a synthetic software-services tender.

The sponsor locks a requirement to build a static incident-status dashboard for an
open-source project. The dashboard must consume a specified JSON shape, render
responsive states, include concrete accessibility notes, provide a reproducible
testing and deployment plan, and describe maintenance.

The five criteria and weights are:

- C1 Technical compliance — 3000 bps — mandatory
- C2 Delivery plan — 2000 bps — mandatory
- C3 Accessibility — 2000 bps — mandatory
- C4 Testing and documentation — 1500 bps — non-mandatory
- C5 Maintenance — 1500 bps — non-mandatory

A valid proposal is evaluated criterion by criterion. PASS, PARTIAL, and FAIL
map to 100%, 50%, and 0% of the criterion weight. INCONCLUSIVE is not awardable.
Proposal A is intended to qualify; Proposal B deliberately fails the mandatory
accessibility criterion.
