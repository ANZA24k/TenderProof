Protocol flow

Four gates. One deterministic decision.

Semantic review is bounded by evidence and cannot directly choose the winner.

01

Commit

Each wallet locks one lowercase SHA-256 digest of the exact proposal bytes before the deadline.

DETERMINISTIC
02

Reveal

The applicant publishes a commit-pinned raw URL. GenLayer independently hashes the retrieved bytes and evidence.

BYTE-AUTHENTICATED
03

Review

Leader and validator fetch the same locked material and assess every rubric criterion independently.

CONSENSUS
04

Settle

Fixed score buckets, mandatory rules, tie breaking, and one award/refund path run in contract code.

Read before relying on it

Transparent about the edges.

TenderProof is not encrypted sealed bidding, legal procurement, identity verification, or production escrow. Commitments protect content only while it remains private. Studionet GEN is test value. Network availability and validator disagreement can leave a proposal unresolved.
